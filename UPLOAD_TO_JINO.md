## 🚀 Пошаговая инструкция

### Способ 1: Через FileZilla (SFTP - рекомендуется)

1. **Скачайте и установите FileZilla:**
   - https://filezilla-project.org/
   - Выберите FileZilla Client

2. **Подключитесь к серверу:**
   - Откройте FileZilla
   - Введите данные:
     - **Хост:** `sftp://debdbd0f4ad5.hosting.myjino.ru`
     - **Пользователь:** `j49565549`
     - **Пароль:** (ваш пароль)
     - **Порт:** `2222`
   - Нажмите "Быстрое соединение"

3. **Загрузите файлы:**
   - В левой части (локальный компьютер) перейдите в папку `logistics-site`
   - В правой части (сервер) вы должны быть в корневой директории `/`
   - Выберите все файлы и папки (кроме исключенных - см. ниже)
   - Перетащите их на сервер или используйте контекстное меню → "Загрузить"

### Способ 3: Через командную строку (Linux/Mac)

```bash
# Создайте архив проекта (исключая ненужные файлы)
cd logistics-site
tar -czf project.tar.gz \
  --exclude='node_modules' \
  --exclude='.next' \
  --exclude='.git' \
  --exclude='.env.local' \
  --exclude='*.log' \
  .

# Загрузите через SFTP
sftp -P 2222 j49565549@debdbd0f4ad5.hosting.myjino.ru

# В SFTP консоли:
cd /
put project.tar.gz
exit

# Затем подключитесь по SSH и распакуйте
ssh j49565549@debdbd0f4ad5.hosting.myjino.ru -p 2222
tar -xzf project.tar.gz
rm project.tar.gz
```

## ⚠️ Важные замечания

1. **Права доступа:**
   - Убедитесь, что файлы имеют правильные права доступа (обычно 644 для файлов, 755 для папок)

2. **Пассивный режим FTP:**
   - Если используете FTP и возникают проблемы, включите пассивный режим в настройках клиента

3. **Безопасность:**
   - Предпочтительно использовать SFTP вместо FTP
   - Не храните пароли в открытом виде

4. **Структура папок:**
   - Все файлы должны быть в корневой директории `/`
   - Структура должна сохраняться (app/, components/, data/, public/)
