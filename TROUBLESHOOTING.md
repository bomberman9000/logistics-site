# 🔧 Решение проблем с подключением к Jino.ru

## Проблема: "Connection closed"

Если соединение закрывается сразу после подключения, это может быть из-за:

### 1. SSH доступ не активирован в панели Jino

**Решение:**
1. Войдите в панель управления Jino
2. Найдите раздел "SSH доступ" или "Управление доступом"
3. Активируйте SSH доступ
4. Возможно, нужно разрешить доступ с вашего IP

### 2. Используйте другой метод доступа

**Вариант A: Через панель управления Jino**
- Используйте файловый менеджер в панели Jino
- Загрузите файлы напрямую через веб-интерфейс

**Вариант B: Через FTP/SFTP клиент (не терминал)**
- Используйте FileZilla или WinSCP
- Может работать лучше, чем командная строка

### 3. Проверьте настройки в панели Jino

1. Войдите в панель Jino
2. Проверьте раздел "SSH доступ"
3. Убедитесь, что SSH включен
4. Проверьте, нет ли ограничений по IP

## Альтернативные методы загрузки

### Метод 1: Через веб-файловый менеджер Jino

1. Войдите в панель управления Jino
2. Найдите "Файловый менеджер" или "File Manager"
3. Загрузите архив `logistics-site-upload.tar.gz`
4. Используйте встроенный терминал в панели для распаковки

### Метод 2: Через FTP/SFTP клиент (FileZilla)

1. Скачайте FileZilla: https://filezilla-project.org/
2. Подключитесь:
   - Хост: `debdbd0f4ad5.hosting.myjino.ru`
   - Порт: `2222` (SFTP) или `21` (FTP)
   - Пользователь: `j49565549`
   - Пароль: (ваш пароль)
3. Загрузите архив
4. Используйте терминал в панели Jino для установки

## Контакты поддержки Jino

Если ничего не помогает:
1. Обратитесь в поддержку Jino через панель управления
2. Уточните, активирован ли SSH доступ для вашего аккаунта
3. Спросите о правильных параметрах подключения

## Рекомендуемый подход

**Используйте веб-панель Jino:**

1. Войдите в панель управления
2. Найдите "Файловый менеджер" или "File Manager"
3. Загрузите `logistics-site-upload.tar.gz`
4. Найдите "Терминал" или "SSH консоль" в панели
5. Выполните команды установки через веб-терминал

Это обычно работает надежнее, чем прямое SSH подключение.
